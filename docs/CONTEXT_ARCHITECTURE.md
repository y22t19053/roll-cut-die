# RCD 上下文管理规范

来源：创作者《RCD Context Architecture：长期上下文管理规范》（2026-11-20，本项目会话 m02103）。完整历史的保存范围与单次调用的输入量分别管理。本规范适用于 RCD，不修改 DSH 全局配置。

## 四层与读取顺序

| 层 | 唯一职责 | 当前入口 |
|---|---|---|
| L0 项目宪法 | 稳定身份、已确认机制、授权和职责；派发只摘取相关条款 | [精简宪法](RCD_CONSTITUTION.md) |
| L1 当前状态 | 验证基线、发布版本、证据、阻塞和下一动作 | [项目状态 §1](PROJECT_STATUS.md#1--一句话状态)；实际 Git 状态优先于快照 |
| L2 任务包 | 此任务相关代码范围、必要接口、测试数据与验收；用完即封存或链接 | [入口与模板](#任务包) |
| L3 原始档案 | 原始对话、原始指令、旧设计、失败记录、日志、Git 版本 | [历史目录](history/)、[决策日志](RCD_DECISION_LOG.md)、[原始总指令](SOURCE_MASTER_DIRECTIVE.md)、Git 与已授权会话档案 |

常规调用只读与任务有关的 L0 摘要、L1 当前条目与 L2；先查文件符号、章节和决策编号，若证据不足才定向打开 L3。项目状态后面的历史章节留在原地，不能因压缩删除原文。摘要标明来源（路径及章节、会话/消息、决策编号或提交）；不可访问的外部档案写“未取得”，不假称完整覆盖。

## 每路由单独预算

按实际模型 ID **加接入通道**分别登记：最大窗口、长输入计价阈值 T、普通/长段输入费率、缓存读写费率、输出费率、可得的实际成本，附币种、单位、来源及核验时间。真实中转费率优先；官方价格只可另列参考，不代填。当前未核实的值保留 `未知`，证实无独立长上下文价阶才写 `无 T`。无 T 时用独立窗口/成本上限；T 未知时先估算输入并使用任务窄包，不推定已进入某价格区。计数须按通道口径，含实际随请求发送的系统提示、工具描述和工具结果；避免重复回注原始输出。

| 按预计计费上下文长度 / T | 操作 |
|---|---|
| <60% | 绿色，正常按需加载 |
| 60% 至 <70% | 黄色，检查重复材料和预留后续工具读取空间 |
| 70% 至 85% | 橙色，先精简到任务所需证据 |
| >85% | 红色，先写检查点并轮换会话；只有依赖完整相关上下文的高价值任务例外，记录原因 |

窗口容量仍是独立硬限制。重要调用回执记入[模型调用日志](MODEL_CALL_LOG.md)，包含任务号、实际路由、输入/缓存输入/输出/可得推理 token、上下文长度、是否触发长段价阶、实际成本，缺项标 `未知`；不以缓存大小倒推实际阈值，不记录凭据。

## 任务包

每项任务单独整理（可使用同一格式的精简派发正文，不必新建任务台账）：任务号与结果目标；基线提交和脏文件；关联的 L0 约束；可写文件和必要接口；证据路径或行号；已试与失败原因；验收条件与复现方式；不在范围的内容。发给模型前问：“删掉这份材料，会改变本次判断或实现吗？”不会就不发。

Sol 读全局 L1、任务状态、关联决策与证据。Astra 只在重大争议接收完整**相关**架构和反证。Gemini/Claude 拿各自模块资料与冻结接口，实现任务采用单一写入者。Kimi 只拿研究问题与资料，1017 拿具体文件及验收，Qwen 只拿批处理所需数据。默认使用独立任务上下文，不继承整段聊天。

结项或红区切换前写检查点：结果、提交或工作树 diff、真实测试证据、新决策及状态、未解决问题、下一动作与交接路径。更新 L1 与相应档案索引，再由下一任务从新包继续。检查点和项目档案不是原始记录的替代品。
