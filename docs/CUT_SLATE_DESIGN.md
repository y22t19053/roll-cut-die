# 场记板设计（CUT SLATE）

场记板是这款游戏的视听签名：开场、主动剪辑、死亡都过它。它必须一眼认得、一耳记住、重复几百次不烦。
本文件定义表现与节奏，实现归 SlateController（交接书 §14.2）。**三个总时长与撞击帧以 `scripts/ui/slate_ui.gd` 的实现为准**：1.95 s / 1.35 s / 2.05 s，撞击帧 0.34 s / 0.02 s / 0.62 s。凡代码尚未做的部分，本文直接标「尚未实现」。
所有时间按真实时间算，不受 `time_scale` 影响；60fps 只是取整口径。

## 1 · 板面构成

- 板体比例 3:2。1080p 下 720×480，居中偏上 6%，投影柔和 8px。
- 顶部斜纹带：高 64px，黑白 45° 条纹，条宽 32px，两端各留 24px 直边，避免和圆角打架。
- 合页拍板：横贯整块板，高 96px，铰链在左侧，最大开 0.34 rad ≈ 19.5°。用三条平行细线表示板材厚度；拍板下沿与斜纹带共用同一组 45° 角度，合上时条纹接成一条直线。
- 字段四格：SCENE 与 TAKE 在左，DIRECTOR 与 CAMERA 在右。字段名 24px，值 36px，等宽字体，值统一两位数（`01`）。
- 大字区：下方 200px 高、480px 宽，居中。最多 10 个拉丁字符或 6 个汉字；超了缩字号，最小 0.7 倍；再超就是文本写错了，不允许截断。
- 材质：哑光木或树脂，2% 噪点，边缘 2px 磨损高光。不要镜面反射，不要发亮描边，不要彩色滤镜，只有黑白和一点暖灰。
- 层级固定：板体 → 斜纹 → 字段 → 大字。任何时刻不加第五层。

（板体圆角 6px；字段区 672×88，左右各缩进 24px；大字区只用一种字重。）

字段宽度不变：`SCENE` 固定 `12`（第 12 场，整片只有一场），`TAKE` 两位、跟 `take_index` 走并在死亡与放弃时实时改写；`DIRECTOR` 与 `CAMERA` 是固定文本，两个名字都不解释，也不与任何结局挂钩。

## 2 · 三种用途

| | 主菜单开始 | 主动 CUT | 死亡 CUT |
|---|---|---|---|
| 触发 | 点击场记板 | C 键 | 撞上 NPC 或历史幽灵 |
| 之前 | 主菜单静止，板已开 | 任何时刻，直接打断 | 画面先冻结，出 `DIE.` |
| 字序 | `ROLL.` | `CUT!` | `DIE.` → `CUT!`（`RETAKE?` 尚未实现） |
| 角标 | `SCENE 12 · TAKE nn` | `ABANDONED · TAKE nn` | `TAKE nn` |
| 副行 | `ROLL CUT DIE` | 空 | 死因（已本地化） |
| CLACK | 主版 260ms，−3dB | 短版 110ms，−2dB | 主版 260ms，0dB |
| 总长 | 1950ms | 1350ms | 2050ms |
| 撞击帧 | 340ms | 20ms | 620ms |
| 结束 | 世界声渐入，交给玩家控制 | 回 Take 起点 | 进入 Retake |
| 震动 | 3px / 90ms（尚未实现） | 4px / 110ms（尚未实现） | 6px / 160ms（尚未实现） |

三者的板是同一块板，位置、尺寸、材质完全一致；不同的只有节奏、字和声音版本。差异只有四条：

- 主动 CUT 不显示 `DIE.`，死亡 CUT 不显示 `ROLL.`，开场不显示 `CUT!`；主动 CUT 的入场只有 90ms，它是打断，不是仪式。
- 主动 CUT 用短版 CLACK。玩家按 C 的频率可能是死亡的三倍，声音必须更干。
- 死亡 CUT 的 `DIE.` 从第 0ms 就在板上，板带着这个词进场；620ms 才换成判决 `CUT!`。死于什么是原因，板是判决。
- 只有主菜单那次，板在 exit 之后把世界声从 −18dB 推到 0。

## 3 · 逐帧时间表

每格是 `起始 / 时长`，单位 ms。撞击帧（clack hit）时长为 0，它是音频起点，也是所有震动的起点。

| 阶段 | 主菜单开始 | 主动 CUT | 死亡 CUT |
|---|---|---|---|
| 总长 | 1950 | 1350 | 2050 |
| enter 入场 | 0 / 200 | 0 / 90 | 0 / 120 |
| headline 大字 | 0 / 0 | 0 / 0 | 0 / 620（`DIE.`）→ 620 换 `CUT!` |
| stick open 开板 | 120 / 200 | 80 / 60 | 180 / 220 |
| stick close 合板 | 340 / 70 | 20 / 60 | 620 / 60 |
| clack hit 撞击 | 340 / 0 | 20 / 0 | 620 / 0 |
| subline / corner | 400 / 160 | 90 / 100 | 640 / 120 |
| hold 停留 | 560 / 1190 | 210 / 1040 | 760 / 1140 |
| exit 退场 | 1750 / 200 | 1250 / 100 | 1900 / 150 |

- enter / stick open：从 0.96 缩放、y+40px、ease-out 进场，透明度 100ms 淡入、300ms 淡出（实现在 `_process`）；拍板开到 0.34 rad ≈ 19.5°，与入场重叠 40–60ms。主动 CUT 只开 60ms，越急越短。
- stick close：0.34 → 0，缓动 `a*a`（慢起、硬停），最后一帧必须是完全闭合的一帧。
- **撞击帧就是 CLACK 的起点**。现在合盖从撞击帧才开始、70ms（CUT 为 60ms）之后才落到位，听觉比视觉早。要"合上才响"就把 CLACK 挪到合板结束（410 / 80 / 680ms）——**尚未实现**，音频与时间表要一起改。
- 大字逐字符显现，16ms 一个字，`CUT!` 4 字 = 64ms，留 20ms 余量。开场的大字第 0ms 就在，只有副行是后出的。
- hold / exit：板不动，只保留 UI 漂移（见 §5）；主菜单在这段把世界声从 −18dB 渐入到 0（600ms 起，240ms）。exit 板体上移出画、遮罩从中心打开，主动 CUT 的 exit 只有 100ms，它必须比死亡快。
- 死亡 CUT 的 `RETAKE?`（原设计 840–1020ms 插入）**尚未实现**：2.05s 播完直接进 Retake。三套时间表都是独立资产，不做倍率缩放——缩放会让死亡比开场还快，观众会以为出 bug 了。

## 4 · CLACK

| 元素 | 时间窗 | 做法 | 电平 |
|---|---|---|---|
| 瞬态 | 0–6ms | 2–6kHz 一次扫过，单峰，无预延迟，第 0 个采样就是峰 | 峰值 −1dBFS |
| 板材体 | 6–60ms | 300–900Hz 少量共振 + 1.2kHz 木击 | −6dB |
| 低频冲击 | 60–180ms | 60–90Hz 正弦指数衰减 | −8dB |
| 房间尾 | 180–260ms | 12–18ms 早期反射，湿声 | −24dB |
| 主版总长 | 260ms | 上面四段相加 | |
| 短版总长 | 110ms | 只留瞬态 + 板材体，去掉低频与尾巴 | 峰值 −2dBFS |

为什么它必须扛得住几百次：

- 尾巴短、瞬态唯一。超过 260ms 的尾音，八秒内重复二十次就糊成噪音；叠层、第二次撞击、超过 ±2% 的随机变调，都会让每次听都是新声音，记忆点会散。
- 同帧去重。一帧内只允许一个实例；连按 C 不叠加播放，只重置动画。
- 三条轮换。同一 CLACK 存三条，±2% 音高、±1.5ms 起始微差，避免机械重复。
- 电平锁。主菜单 −6dBFS，CUT 与死亡 −9dBFS；不因为频繁播放加增益。撞击帧把世界声 duck 到 −18dB，60ms 内恢复。
- 三秒内重复同一种 CUT，自动改用短版并再降 2dB。玩家连死十次时，耳朵应该只剩节奏，不剩音量。
- Final Cut 的章节切换复用主版，作为整场唯一的"回声"。

| 资产 | 时长 | 用在哪 | 备注 |
|---|---|---|---|
| `clack_main_01..03` | 260ms | 主菜单、死亡、章节切换 | 三条轮换 |
| `clack_short_01..03` | 110ms | 主动 CUT、三秒内重复 | 更干，无尾 |
| `board_open` | 180ms | 开板 | 木头摩擦，电平 −18dBFS |
| `board_exit` | 120ms | 退场 | 布帘擦过，电平 −20dBFS |

## 5 · 运动规则

以下四条都是设计值。`slate_ui.gd` 目前只做淡入淡出与合板，这四条全部**尚未实现**。

- 震动：主菜单 3px / 90ms，主动 CUT 4px / 110ms，死亡 6px / 160ms。单次衰减，正弦平方曲线，方向固定左下（−1, +1）。同帧多次触发只取最大幅度，永不叠加。
- 冻结帧：撞击帧替换为 2 帧高对比静帧（死亡为 3 帧），随后恢复。这是唯一的画面停顿，不加慢动作。
- 世界冻结与 UI 漂移：物理、NPC、历史幽灵在撞击帧停住，UI 时钟不受影响，动画、字幕、淡入照常走；冻结期间板体与斜纹带做 ±1.5px、周期 1.2s 的极慢漂移，让画面"没死透"。字段与大字不漂移，它们要能读。
- 不做：超过 1 帧的色差、镜头模糊、胶片刮痕闪烁。板是硬的，画面不应该是软的。

## 6 · 可访问性

- 减少动态：关掉震动与冻结帧；板体改 120ms 交叉淡入；拍板不做连续旋转，改为 2 帧跳切（开 → 合）。CLACK 保留，优先用短版。
- 声音字幕：CLACK 同帧在屏幕下部安全区出现 `[场记板合上]` / `[clack]`，停 700ms，不与大字区重叠。只给这一个声音配字幕，其他音效不加。
- 高对比：斜纹带降为纯色带 + 1px 描边；大字与底色对比度不低于 7:1。
- 字号与闪烁：大字区在 1080p 下最小 36px，减少动态模式下不缩小；不使用高于 3Hz 的闪烁作为反馈。震动开关与减少动态是两个独立开关，可以只关一个。

## 8 · 刻意不做的

- 第一版不做 3D 实体板。先用 2D UI 把节奏和时间表验证完，再评估实体化（交接书 §06.5）。
- 板面不加贴纸、胶带、手写笔记；除了斜纹、四个字段、大字，什么都没有。也不做第二块板：结算、设置、暂停都不需要板。
- 开板不超过 0.34 rad（约 19.5°）。再大就变成弹簧，不再是板。
- 不做第二块板：结算、设置、暂停都不需要板；也不用板解释剧情，板只报场次、条数、口令。
