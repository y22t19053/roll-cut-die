# RCD 项目宪法 · L0

**roll cut die**，MacGuffin Works，Godot 4 / GDScript，Windows PC。核心承诺：**YOU'LL NEVER TRUST WASD AGAIN.** 项目与其他游戏独立；只复用通用工具和获授权资产。

- **ROLL**：同一 WASD 输入驱动人物并改变镜头，使屏幕方向变得不可靠，但规律确定、可学。创作者认可 ORBIT30 试玩手感；它是受保护的对照基线，不是最终锁定。保留 CHASE/SNAP。难度首先来自空间判断、时序和选择，不靠堆敌人或随机输入。
- **DIE / CUT**：与活动 NPC 或已武装历史幽灵身体碰撞即死。MARK 管个人锚点容量，主动 CUT 归档 Outtake 并按快照回退，死亡消耗 Retake。时间线用真实锚点和场景证据，不凭空构造预览。Hybrid 补给、Dynamic 上限和跨线共享库存属长期方向；全局库存不随时间线回退，所以分离 TimelineState 与 GlobalState。
- **历史循环**：成功轨迹成为后续周目的碰撞幽灵。CUT/失败轨迹保留为 Outtake，可试验非致命帮助；旧时间线不覆盖，同一时刻一条活动线。Final Cut 用真实记录。Corner Lock、视角机关、不可能空间等候选在证据和创作者裁决前仍是实验。
- **生产边界**：Sol 总控并可直接实现，Gemini 有可靠路由时做平级并行实现，Claude 可用后重新加入；Astra 重大争议按需，Kimi 独立审查，DeepSeek 与 Qwen 做辅助。标真实模型/通道和贡献，禁止假称调用。每个核心文件同一时间只有一个写入者，设计结论与真实证据分开。
- **授权**：常规可逆项目研发自主；不公开发布、不可逆投稿，不毁唯一备份，不动系统安全，不泄露凭据，不新增付费。重大玩法方向和不可逆变更由创作者最终裁决。自动输入、窗口实测、原版 EXE 和真人试玩各为独立证据。
