# 西侧转角：证物路线 A/B（待真人验证）

**问题**：玩家被墙堵住、镜头仍在转时，一条短地面标记能否帮助他们自己发现可以横移脱困？只比较地面标记，不调整 ORBIT30、不改正式地图和报告规则。

**材料**：[A 场景](../../tools/corner_evidence_a.tscn)无标记，[B 场景](../../tools/corner_evidence_b.tscn)有标记。两者共用[实验脚本](../../tools/corner_evidence.gd)，从正式出生点出发，在西侧证物路线加同一面墙。B 只增加不碰撞的短标记。实验场景不读写正式存档，正式关卡与零证物 REFRAME 捷径保持原样。

**机器证据**：Godot 4.3，[键盘探针](../../tests/probe_corner_evidence.gd)通过 10 项检查。两组相同输入在 `(2.794444, 0.05, 6.669504)` 被墙挡住，继续按住 W 一秒，位置不动、镜头转 30°。横移后从同一站位 `(4.175579, 0.05, 4.595647)` 按 E 两次取得 SCRIPT PAGE。F4 不读正式档；最终复验前后正式存档 SHA 一致。早期试跑曾走默认写盘路径；之后加了隔离回归，不回写未知旧档。这个结果只证明路线和对照有效，不能证明标记帮助了人。

**真人首测**：每人只玩首次随机分配的一组；两组交替发放。开场只告知 WASD 移动、E 检视和收取，以及目标是取得剧本页；不给路线，不提墙角或地面标记。记下首次在墙边停住后的第一个脱困方向、挡住到脱困的时间、重新撞墙次数、是否拿到证物。结束后先问「刚才怎么决定下一步往哪走？」再问「镜头转动时，你看到了什么？」将自主提到并使用镜头提供的信息，与只沿线走分开记录。中止/需要提示也保留。第一小批用于发现障碍，不据此宣称统计显著。

**取舍**：若 B 降低盲撞且玩家仍借镜头重定位，再扩大验证。若 B 只让人盯线走，用地标代替连续引导；若两组都读不出出口，先改可见性而非转速。现阶段均属实验。
