# Backlot 西窗：第二条回程的真实窗口取证

**在本次正常首条轨迹、第二条直接走到西窗的路线上，幽灵在画面中实际可见。** 这不是仅凭世界坐标或 HUD 残影数推断：在同一物理状态下，仅隐藏幽灵重绘，得到局部像素差。没有真人参与，不证明玩家一定注意到、认出或理解它。

- 版本：`2d171879274486e1c6faaf2819d76e9173287266`；Godot 4.3，Windows 游戏窗口 1600×900。用 `godot_run_project` 进入 [Backlot 场景](../../scenes/backlot/backlot.tscn)，端口 9198，结束后已关闭。临时工作树开启独立 `user://`：`RCD-Research/backlot-return-2d17187`，不使用正式进度。
- 输入：复用 [walk_test 路线](../../scripts/backlot/walk_test.gd#L27-L63)，用物理帧方向输入从出生点依次走 `(12,28) → (12,25.8) → (10,25.8) → (10,4) → (28,4) → (28,3.22)`，调用正常交互断电后重拍。未瞬移、未注入轨迹、未关闭危险。首条录得 **16.60 秒**；第二条生成一个回放实体，直接走向 `(12,30)`。
- 抓帧：到达观察点时回放播放头为 **1.60 秒**。玩家 `(12.110,0.050,30.000)`，幽灵 `(8.943,0.050,28.000)`，相距 **3.75 米**。用当前相机投影 `TAKE 01` 标签原点得 `(780,744)`，身体中心 `(790,786)`（左上原点，四舍五入）。此帧处于幽灵初显阶段，不说明此刻具有碰撞危险。
- 像素验证：先强制绘制正常帧；不推进物理帧，只隐藏幽灵并重绘对照，随后恢复可见。RGB 三个通道最大绝对差大于 8 的有 **7,509 像素**，全部落在 `x=729…830, y=730…846`。标签点 RGB 从对照 `(95,97,100)` 变为正常 `(131,192,212)`；身体点从 `(85,85,88)` 变为 `(138,195,214)`。正常帧可读 `TAKE 01` 和「第 02 条 · 1 个残影」，有半透明青色身体。
