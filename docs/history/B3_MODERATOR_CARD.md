# B3-B｜主持人卡（不要把本页投给参与者）

**参与者只看这句话**：「请在场景中找到并取得剧本页。W、A、S、D 移动，E 检视或收取物品。你随时可以停止。」不要提墙、镜头、画线或另一版本；不要指路。接受帮助的时刻就结束独立完成计时。

**开始前**：分配 P 加三位流水号，不写姓名。记是否玩过、看过路线或知道目的；知情者单列。按两人一块，抛硬币选首位 A/B，另一人取另一组。每人的第一次暴露才用于组间比较。人少需交叉时第二次交换条件，单列第二次，不能当另一名新玩家。使用同一提交、同一 ORBIT30、分辨率与键盘，关闭通知，玩家看不到启动参数。分别取得本地游戏操作记录及录像同意；拒绝或撤回时不采相应数据，不因此要求对方继续。只录游戏窗口，无摄像头、桌面或麦克风。

**保护存档**：用本机已安装的 Python 3 运行 `tools/west_trial_operator.py prepare A`，取得独立工程路径（B 组换 B），只在该副本开测。另开交互终端运行同一解释器 `tools/west_trial_operator.py guard A --participant P001 --order first`（替换条件和编号）；核对它监控的是正式游戏当前的 user:// 路径。守护器仅采样哈希，不改文件；报告异常时主持人立即中止、不恢复，整次作废。游戏关闭后回观察终端按 Q，保存最终摘要。每次单独开一份。正式试玩 EXE 不含实验关，不用它收集 A/B 样本。经同意后使用既有 OBS 窗口捕获，录制几秒回看确认非黑屏后才开始正式计时。去除能识别人的文件名；录像和原始数据仅存本地，不进 Git。

**采集开关（主持人操作）**：`prepare` 只备份当前提交到独立副本并选择 A/B 场景，不代表同意，也不会开始录制。取得输入记录同意后，由主持人在该副本的 Godot 启动配置中传入 `-- --west-trial-consent`：第一个 `--` 分隔游戏自定义参数，分隔符后只给这个开关。运行项目；确认输出 `West trial armed, not recording.`，等开场板结束、角色仍在出生点、窗口有焦点，主持人才按 F8。输出 `West trial recording:` 后记匿名数据编号。未出现该行不得把本轮记作已采集。求助按 F9，停止按 F10；录像另行停止。不愿采输入者不要设置开关，不能用 QA 参数替代同意。仅改临时副本，不改正式工程。

**Windows 切窗验收（主持人自测，不占真人样本）**：用单独的隔离副本和独立数据编号，先开存档守护。用任务管理器确认运行游戏窗口的 PID（不要填 Godot 编辑器的 PID）。在另一终端运行 `python tools/observe_trial_focus.py <游戏PID> --seconds 90`；该工具只观察，不夺焦点。单击游戏，等开场结束后按 F8，确认开始录制，再 Alt+Tab 切到另一应用。观察器须先输出 `game_foreground: true`，再输出 `OBSERVED_GAME_TO_OTHER`；仅看到 `false` 或 `null` 不算。核对同次数据编号的封卷原因为 `focus_lost`，配置指纹匹配准备回执，守护器结束为 `UNCHANGED`。任一缺失记未验证；即使通过，也仅作为主持人现场 QA，不纳入首曝样本。不要为了使其通过而强制抢焦点或更改系统设置。

**逐人记录**：编号/先验经验/条件/顺序/提交/录像同意/输入同意/数据编号；首次阻挡的录像时码；首个有效脱困按键及其时码；越过墙端或有效退回至可另选路的时码（注明是哪种）；期间撞墙重试次数和长按停滞时长分别记录，一次长按不能算多次；独立取得、求助、超时或退出。未触墙记 NA，不能填 0 秒。每人上限 5 分钟，或主动退出。从 F8 开始计真实时间；到期后的第一次写入只封卷为 `time_limit`，不再采按键或位置。另行同意的 OBS 录像仍需主持人手动停止。镜头在转本身不等于玩家有意观察。

**封卷后复核**：用 Python 3 运行 `tools/analyze_west_trial.py <本次副本中已关闭的 trial.jsonl> --condition A --source operator_opt_in --config-sha256 <本次准备回执的 project_config_sha256>`（B 组换 B；从准备回执取值，不从试验记录头复制）。指纹不符记无效，旧记录缺指纹记未核实。把退出码、条件、原始文件 SHA256 与匿名编号一起保存在本地。`status=ok` 只说明记录结构一致。另核对 `orbit30_observation`：`matched_samples` 表示记录的每个样本都是 ORBIT 且配置为 30°/秒；`off_protocol`（例如中途切到 SNAP）单列，`unknown` 不算作已核实的 ORBIT30。保留原始记录，不因偏离协议删人。`contact_to_release_us` 是首次碰撞接触消失，不等于成功脱困，横移键也不一定是正确方向。用录像核对越过墙端或退回可选路线的时刻。`null` 不补零，QA 不混入参与者结果。

**结束后**先问「刚才你怎么决定下一步往哪走？」记录原话，再问为什么走不过、镜头有什么帮助或干扰、地面是否影响决定、能否预测下一键。分别编码自主观察/试探/跟随标记/偶然/未知，保留反例。录像、遥测、原话互相矛盾时保留三者，不强行归类。汇总列每组首次触墙人数、独立取得人数、首键有效人数及其分母，逐例脱困时长、求助和退出，不因未完成删样。没有合格参与者时样本数为零，保留设计未决。
