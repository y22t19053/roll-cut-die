# B3-D｜同一路口，能否重试同一个让行决定？

**待探索，独立灰盒；不进正式地图。** 假设：成功 Take 的轨迹如果横穿下一轮的路线，MARK/CUT 能让玩家在同一观察位置、同一世界时刻重新做一次过路决定。NPC 放在隔开的东侧，避免把随机的碰撞来源误认成历史轨迹。

**相关接口**：`tools/junction_lab.tscn`；`tools/junction_lab.gd` 的 `route_points()` 提供真实世界 XZ 路点，`junction_snapshot()` 只观察。成功报告沿用正式逻辑；不写正式进度，不人工添加幽灵。与西侧涂装首曝试验分开，后者的参与者不能提前看这份路线说明。

**机械验收门槛**：首轮走 A 并报告；次轮走 B 并在观察点 MARK；记录成功轨迹来源、幽灵危险区已激活且由西向东穿口的世界时刻；CUT 回 MARK 后再量同一事件的时刻、方向、轨迹数和恢复位置。不要把“起了场景”或“生成了节点”写成通过。记录实测偏差，不要求渲染帧逐帧相同。

**后续真人题**：第一次通过前，让参与者指出下一位到路口的是谁；回到 MARK 后让其自行决定等或走，不提示安全秒数。分开记预测、实际行为、死亡来源和事后解释。两次均存活可能只是一直等，不等于掌握了时机；若只会复述路线，换同一交口的到达时差再验。本包不含真人结果。
