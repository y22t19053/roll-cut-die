## 2. 核心三大机制（ROLL · CUT · DIE）

### 2.1 ROLL — 镜头运动与角色移动耦合

- 玩家 WASD/方向键移动与摄像机轨道运动直接耦合，空间方向认知与惯性预判构成操作地基。
- **硬基线（严禁擅自篡改）**：
  - 摄像机基准角速度：**`ORBIT 30°/s`**（另有历史验证过的 `CHASE`、`SNAP` 模式代码保留于 `scripts/camera/`）。
  - 侧倾雕刻感：**`LEAN_CARVE = 0.30`**（见 `docs/RCD_MISSION_BRIEF.md`）。
  - 取景规格：16:9 横屏基准（`53°–55°` FOV / `12m` 视距，见 `D-069`，严禁为移动端单独改镜头焦距从而撕裂空间规则）。
- 绝对禁止把 ROLL 退化为「普通俯视角角色移动 + 装饰性镜头抖动」。

### 2.2 CUT — 场记板打板、资源博弈与时间抹除

- 玩家主动按下 `C` 呼出场记板/剪辑台（`scripts/relay/cutting_desk.gd`、`scripts/ui/slate_board.gd`），通过打板（CLACK）放弃当前未完成的走位，回到已布置的 `MARK` 检查点。
- **不是无代价的无限撤销键**：
  - `MARK`（`M` 键落点）与 `CUT`（`C` 键重拍）拥有明确配额预算（如 Novice `6 MARK / 3 CUT`、Expert `6/3`、Master `3/2`）。
  - 执行 `CUT` 会抹除该 `MARK` 之后的当前段行动，同时在移动 `MARK` 上恢复打板前的角色真实速度矢量（提交 `7844510` 实测：理论滑行 `0.171111m`，实测 `0.171112m`）。

### 2.3 DIE — 公平、可预测、瞬间复拍的 NG 反馈

- 玩家与历史 `Ghost`、轨道车（Dolly）、片场危险机关或剧组碰撞体发生物理接触时触发拍摄失败（`NG / TAKE FAILED`）。
- **核心体验红线**：
  - 死因必须一眼可辨、物理判定确定、恢复极快（支持 `SafetySplice` / 强制剪辑台回退或重开）。
  - 在 `relay` 主线中，死亡同时驱动片场空间事件（如剧组将当前布景 **180° 翻景旋转**，迫使玩家重新建立方向映射）。

## 3. 核心差异化资产：Ghost 与历史 Take

Ghost 是 RCD 区别于普通动作游戏与传统 Roguelike 的灵魂机制（代码位于 `scripts/ghost/` 与 `scripts/relay/`）：

1. **真实行动录制与确定性重放**：每一条成功完成的 Take 都会被逐帧记录；在后续 Take 中，过去的自己以实体碰撞对象重返场地，严格按原路线行动且**绝不给现在的你让路**。
2. **碰撞隔离原则**：Ghost 与当前玩家发生真实碰撞，但 Ghost 之间互不碰撞，也不随意篡改世界全局状态。
3. **已验证的时空解谜价值**：
   - 灰盒确定性测试已证明：同一 `MARK`、同一条 `Ghost` 轨迹下（例如 Ghost 固定在 `4.050s` 通过交叉口），玩家等待约 `26` 个物理帧再按 `W` 可安全擦身通过，提前约 `0.55s` 出发则必然撞击 NG。
   - Mauspi Lab. 外部评审亦明确指出「过去 Take 物理返回 + CUT 抹除后续路线 + 短局 One More Try」构成了极具吸引力的自生成时空谜题。
4. **必须持续守卫的架构问题**：
   - Ghost 的世界坐标 vs 局部布景坐标基准（尤其在地图拼接、180° 翻景 Redress 后的坐标变换规则，当前部分场景仍属 `UNVERIFIED` 设计边界）。
   - Ghost 动画速度、碰撞体位置与危险时间窗口必须共用**唯一确定性时间轴**，严禁只改动画播放倍速而脱离物理步进。
   - **机器测试 ≠ 真人理解**：历史 646 条断言记录覆盖已测试的数学与状态机路径，不能替代真人对多 Ghost 路线的可读性验证（当前外部真人独立试玩样本仍标记为 `0 / UNVERIFIED`）。

## 4. 片场世界观与标准术语表

游戏机制与电影片场调度语言自然咬合，严禁生造拗口伪术语，严禁把普通系统按钮强行包装成晦涩词：

| 游戏内行为 / 状态 | 标准片场术语（EN / ZH） | 代码与设计约束说明 |
|---|---|---|
| 单次连续行动过程 | `TAKE` / 一条戏 | 成功完成后沉淀为后续场的历史 Ghost |
| 碰撞/失误导致拍摄失败 | `NG` / `TAKE FAILED` | 统一失败反馈，配合翻景或剪辑台抉择 |
| 主动放弃当前走位回退 | `CUT` / 喊卡重拍 | 消耗 CUT 配额，抹除回退点之后的轨迹 |
| 场地内打点存档锚点 | `MARK` / 落位标记 | 消耗 MARK 配额，记录位置与瞬时动量 |
| 幕间休整与器材/增益三选一 | `MEAL BREAK` / 放饭 | 一幕（Act）结束后的片场整备选择 |
| 剧组迁移至全新拍摄地点 | `COMPANY MOVE` / 转场（大转场） | **注意拼写：必须是 `Company Move`，严禁误写为 `Compound Move`** |
| 同一片场内换机位或子区域 | `LOCAL MOVE` / 小转场 | 同景别/同棚内的局部调度切换 |
| 原地改变/旋转现有布景 | `SET CHANGE` / `REDRESS` / 翻景 | 如死亡触发 180° 布景翻转，需明确 Ghost 坐标映射 |
| 整轮拍摄杀青结算 | `WRAP` / 收工 | 完成全部幕次后的结算与统计 |
| 特殊限时高风险奖励房 | `MAGIC HOUR` / 抢天光 | **仅限特殊限时挑战房名称**，严禁泛指整个游戏主流程 |
| 被踢出或脱离正常布景边界 | `OUT OF FRAME` / 脱景 | 研究池机制：需有明确预警前摇与声音/脚步返回线索 |

## 5. 核心设计原则与治理红线

1. **短平快、高可读场地**：创作者明确偏好短小精悍、边界一眼可见、历史 Ghost 压迫必经咽喉要道的紧凑房间，拒绝空旷跑图。
2. **玩家主导机位与路线（Authorial Blocking）**：道具与成长项应改变观察、方向映射、Ghost 时间窗或片场器材关系，不做纯数值移速堆砌。
3. **去 AI 模板化审美（Anti-Slop）**：严禁霓虹蓝紫赛博 HUD、毛玻璃圆角卡片、无意义发光边框、假技术乱码数字或把单张 AI 图直接垫成死按钮；所有界面元素必须有片场物质依据（通告单 Call Sheet、场记板 Clapperboard、胶布 Tape、剪辑台胶片格）。
4. **研发授权边界**：
   - **主控自主裁决**：日常工程架构、任务拆解、三路 Codex 调度、分支隔离、自动化测试、UI 方案探索与原型迭代。
   - **必须创作者批准**：公开发布/更新线上包、正式报名或修改比赛投稿、付费订阅、账号安全变更、删除唯一备份、覆盖重要历史构建、改变核心玩法方向与重大品牌决策。
   - **创意分级漏斗**：`IDEA`（记录归档）→ `RESEARCH`（可行性调查）→ `EXPERIMENT`（独立分支灰盒原型）→ `APPROVE`（正式合入主线），严禁因随口新点子打断当前正式冲刺。
