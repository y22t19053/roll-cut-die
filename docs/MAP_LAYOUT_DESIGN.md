# 地图布局设计（STAGE OFFICE 12）

本文件的坐标、尺寸、速度全部取自 `data/studio_map.json`（schema_version 1）。数字不在这里发明：要改先改 json，再同步本文件。
单位一律米。原点在西北角，x 向东，z 向南（z 变大＝往南走）。y 是高度，只用于遮挡判断。
玩家碰撞半径 0.32 m，直径 0.64 m。净宽 = 几何宽 − 0.64；净宽 ≥ 0.7 m 才算能过，低于 0.7 就是过不去的缝。
本文件是布局设计，不声明实现状态。

## 1 · 外框与出生点

- 场地 24 × 18 m。
- 外圈墙厚 0.4，四段闭合：北 `[0,0,24,0.4]`、南 `[0,17.6,24,18]`、西 `[0,0,0.4,18]`、东 `[23.6,0,24,18]`。内侧可用范围 x 0.4..23.6、z 0.4..17.6，即 23.2 × 17.2 m。
- 出生点 `(2.0, 16.6)`，西南角，南墙内侧 1.0 m。
- 报告区 `report_zone` 圆心 `(2.6, 15.2)`，半径 1.5 m。出生点 `(2.0, 16.6)` 就压在圈边上（距离 1.52 m），回执口 `(2.2, 15.8)` 与边柜都在圈内，玩家第一眼就能看到"要交东西的地方"和"能捡东西的地方"。

## 2 · 中央办公室块

- 占位 8.0..16.0 × 6.0..12.0，墙厚 0.4，四面闭合，内间净空 7.2 × 5.2（x 8.4..15.6，z 6.4..11.6）。
- 四面各开一门，门洞 2.0 m：
  - 北门 x 11.0..13.0（墙段 z 6.0..6.4）
  - 南门 x 11.0..13.0（墙段 z 11.6..12.0）
  - 西门 z 8.0..10.0（墙段 x 8.0..8.4）
  - 东门 z 8.0..10.0（墙段 x 15.6..16.0）
- 墙段共 8 段：北 `[8,6,11,6.4]` `[13,6,16,6.4]`；南 `[8,11.6,11,12]` `[13,11.6,16,12]`；西 `[8,6.4,8.4,8]` `[8,10,8.4,11.6]`；东 `[15.6,6.4,16,8]` `[15.6,10,16,11.6]`。
- 门洞净宽 = 2.0 − 0.64 = 1.36 m。四扇门都是宽的，不是 choke。

## 3 · 拓扑：外环 + 内环 + 四条连接

```
 z=0.4  ┌─────────────────────────────────────────────────────────┐
        │                     北环  (z 0.4..6.0)                    │
 z=2.2  │   [长桌]                                    [灯架]         │
 z=6.0  │                  ┌───── 北门 ─────┐                      │
        │                  │                │                      │
        │ 西                │    内环        │                东    │
        │ 环                │ ┌──────────┐   │                环    │
 z=8.0  │ [文件柜] ──西门───┤ │ 导演桌    │   ├───东门─             │
        │                  │ └──────────┘   │                      │
 z=12.0 │                  └───── 南门 ─────┘                      │
 z=14.2 │   [木箱]  [道具桌]                        [推车]         │
 z=16.4 │ [边柜] ●回执                                               │
 z=17.6 └─────────────────────────────────────────────────────────┘
        x=0.4                                                  x=23.6
```

- **外环**：办公室四周的走廊。北环 z 0.4..6.0（5.6 m 深）、南环 z 12.0..17.6（5.6）、西环 x 0.4..8.0（7.6）、东环 x 16.0..23.6（7.6）。
- **内环**：内间绕导演桌的一圈。净空 7.2 × 5.2，扣掉导演桌（2.8 × 1.4）与导演的巡逻环后，最窄处只剩 0.6 m（东墙与导演东腿），也就是"跟在他背后走"的那一圈。
- **四条交叉连接**：四个门各 2.0 m。任意两条相邻的外环段之间都有两条路：穿内间，或沿外环绕。这让玩家永远有"绕开 NPC"的选项，也让抄近路变成一次风险选择。
- 取场记板必须进内间；另外三件都在外环上。门是"从安全到危险"的唯一入口，这是全图最重要的结构。

## 5 · 两名 NPC 的巡逻

两人都是 `loop`、`dwell 0.0`：没有停顿点，玩家记不住"他会在哪停"，只能记"他现在在哪"。

**导演 director**：路线矩形 x 9.8..15.0（5.2）× z 7.2..10.8（3.6），顺时针，起点西北角 `(9.8,7.2)`，速度 1.15 m/s。

- 周长 = 2 × (5.2 + 3.6) = **17.6 m**
- 周期 = 17.6 ÷ 1.15 = **15.30 s**
- 南腿（z = 10.8，x 9.8..15.0）占用 5.2 ÷ 1.15 = **4.52 s**，占一圈的 29.6%。这是取场记板唯一的窗口。
- 实现侧记录的一圈约 16.6 s，比几何值多 1.3 s，相当于四个转角各 0.33 s 的转向损耗。15.30 s 是几何下界，16.6 s 是含转向的实测口径（尚未用运行时数据复核）。

**场务 stagehand**：路线矩形 x 17.0..22.6（5.6）× z 2.4..15.2（12.8），顺时针，起点西南角 `(17.0,15.2)`，速度 1.35 m/s。

- 周长 = 2 × (5.6 + 12.8) = **36.8 m**
- 周期 = 36.8 ÷ 1.35 = **27.26 s**
- 南腿（z = 15.2，x 17.0..22.6）占用 5.6 ÷ 1.35 = **4.15 s**，占一圈的 15.2%。对讲机就挂在这条腿的正上方。
- 实现侧记录约 27.5 s，差 0.24 s ≈ 四个转角 × 0.06 s。

危险几何：接触距离 = 玩家半径 0.32 + NPC 半径（**尚未定**，设 0.30）= 0.62 m。

- 场记板 `(12.4,9.9)` 到导演南腿 z = 10.8 的间距 0.9 m > 0.62：**站在板上是安全的**，危险只在"走过去"和"走回来"这两段。
- 对讲机 `(19.6,14.9)` 到场务南腿 z = 15.2 的间距 0.3 m < 0.62：**站在上面一定被判定接触**。必须先等他走开，或者趁他在北段时一次做完。
- 推车南缘 z = 14.6 到场务南腿 z = 15.2 只有 0.6 m：他经过时，你和推车之间钻不过去。东南角在对讲机这一段是"必须等他"的封闭窗口。

## 8 · 视线与遮挡

- 中央办公室四面墙按 2.4 m 高处理（json 未给墙高，**尚未定**）。它高于镜头视平线：站在外环看不到内间的人，只能听见脚步和板声。这是"进门才知道导演在哪"的来源。
- 遮挡体（高 ≥ 1.0）：灯架 2.3、文件柜 1.6、推车 1.1、木箱 1.1、场务推车 1.0、边柜 1.0。它们在地面投出 1.0–1.5 m 的暗区，而 §7 的窄口几乎全部落在这些暗区里：窄口在视觉上也更暗，可读。
- 非遮挡体：导演桌 0.9、道具桌 0.9、长桌 0.85、沙袋 0.4。可以看过去，但脚过不去。
- 等距镜头下，"能看见但过不去"比"看不见"更有用：玩家看得见窄口，也看得见站在窄口对面的导演。
- 遮挡体挡住玩家时应淡出（**尚未实现**）；不淡出会出现在视觉上被柜子完全埋住却还活着的情况。
