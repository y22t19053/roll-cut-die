# RCD 创意资产目录｜B3.2

这是设计检索表，不是功能清单。「基线」指已有对照；「方向」是创作者定下的原则，不等于完整交付；「灰盒」仅指隔离场景；「池」没有准入。依据：[创作者总指令](../SOURCE_MASTER_DIRECTIVE.md)、[设计演化 N-01～09](../RCD_DECISION_LOG.md#L24-L34)、[宪法](../RCD_CONSTITUTION.md)、本轮创作者补充。排序：已有机制的新组合 > 关卡设计变化 > 参数变化 > 轻量辅助机制 > 全新独立系统。

| 类别 | 已有资产 / 明确方向 | 候选、状态与边界 |
|---|---|---|
| 空间 | 世界轴 WASD；ORBIT30 顶墙仍转，对照基线不改。成功后换端已有[交口隔离灰盒](../history/B3_JUNCTION_PACKET.md)，不是全作规则。 | 池：终点坠落回起点或相似地图；不同周目互换端点；错视楼梯、三角、投影通路。方向映射、镜头变换、传送门、折叠、重力与碰撞关系、按视角开门、指定 Take 才可见的路，均未批准取代现规则。先用现有布局测试换端；若只靠背入口，别上新空间系统。 |
| 时间线 | MARK 记真实锚点，CUT 放弃当前片段并按快照返回；同一时刻一条活动线，旧线不覆盖（方向）。 | 当前锚点预览不等于任意时刻可拖动，更不等于可遍历的分支树。分支先问「回退后哪条记录仍在」，不造推测历史。 |
| 经济 | MARK 占锚点容量；CUT 付出进度；DIE 花 Retake。三者代价不合并。 | 长期：Hybrid 普通补给按分支，特殊补给全局唯一；Dynamic 上限、跨线共享库存，库存不回滚。[D-005/006](../RCD_DECISION_LOG.md#L77-L91)；数值未定，切线重复领取特殊补给是反例。 |
| Ghost / Outtakes | 成功实录生成后续致命幽灵；被剪掉或失败的素材留档，不生成致命追兵。 | 可选时间协作 / 路线参考属池。本轮仅[灰盒](../../tools/outtake_echo.tscn)呈现最后一次主动 CUT 的无害路线，可关、限一条；不压机关、不计碰撞、不从所有旧档中选取。死亡片段不在试验范围。 |
| 电影 | ROLL / CUT / DIE / MARK / TAKE / RETAKE 是动作和片场语言，不是菜单换皮；用真实经历而非预制胜利镜头。 | [Final Cut 设计](../FINAL_CUT_DESIGN.md#L18-L31)：成功、死亡、主动 CUT 和轨迹可作素材。实录重组为优先小实验，非本次实现；不能为缺失的一帧编造素材，也不需要游戏内视频编码。 |
| 世界与道具 | 办公室片场的「失物」：账簿称已移交，箱子却还在。导演、场务的证词各有边界；报告可如实写、隐瞒或重排责任。[案件与结局](../CASE_AND_ENDINGS.md#L9-L40) | 场记板背面日期、被改的剧本页、对讲机录音、本地回执，各回答不同事实。封存或不附报告是选择，不是四把同色钥匙。年代家具、电影制作物件可作地标；装饰不自动成为交互道具或机制。 |

**本轮只提升一项到隔离灰盒：主动 CUT 后的一条无害路线。** 未新增正式空间、经济、道具或 Final Cut 系统。灰盒是否值得放进 ORBIT30 交口仍需人测，准入与反例见[研究综合](../research/B3_RESEARCH_SYNTHESIS.md)。
